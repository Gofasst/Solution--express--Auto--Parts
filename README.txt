Solution Express Auto Parts et Multi Service — first prototype

Upload every file in this folder to the ROOT of your GitHub repository.

This prototype is offline-capable and stores data locally in the browser on this device.
It is NOT yet a secure multi-device system:
- no owner login yet
- no cloud database or cross-device synchronization yet
- records do not automatically appear on another phone
- use Settings > Download backup regularly

Before using real business records, the next development step is to add secure owner sign-in and a cloud database with safe offline synchronization.
